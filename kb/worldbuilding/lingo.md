# Closed vocabulary

This book's world vocabulary, in one closed list (`AGENTS.md` §5). A term used in prose or plans that isn't on this list is a defect. A term the sequel needs goes to Daniel as a proposal, and it enters the list only after he approves it.

Every term below is harvested from `~/code/me/cordimancy/cordimancy.md` (cordimancy commit `64b2f69`). The line is where the term first appears, or where canon defines it, if that comes later. A meaning marked *not stated* is a term canon uses without defining. Use it only the way canon does. `~/code/me/cordimancy/translation/naming-terminology-bible.md` served as an index for finding terms. It is not canon, and some of its glosses are wrong. For example, it lists Paka as female.
